# 星曲：祕境

執行本檔前，`xingqu-core-rules` 必須已在上下文中。

規則：探索祕境副本，通關獲得祕寶與可能掉落；每日可進入次數 2 次（每日重置），次數用完可消耗秘境鑰匙進入，但**本流程一律不使用鑰匙**。

畫面資訊：左側關卡列表（寂靜雪原、失落神殿、古代城堡、邊境之地……可捲動），已通關的關卡右側有「已通關」圓標；右側顯示「祕寶」「可能掉落」「推薦戰力」「今日可進入次數」「掃蕩」「開始」兩個按鈕，以及「自動挑戰」勾選框。點選某關卡後外框變橘色。**注意**：進入畫面時預設選中的關卡不一定是古代城堡（實測有時預設停在「邊境之地」，推薦戰力顯示 7,800,000），每次都要先看外框顏色與推薦戰力數字（古代城堡推薦戰力約 3,400,000）確認選對。

前置條件：人物要在「天空之城」。

**進入方式**：主城右下角「征戰」(約1118～1122,545) → 預設在「副本」頁籤（這個頁籤的圖示可左右拖曳捲動，預設顯示「戰役⾜迷宮⾜英雄之門⾜英靈戰役」） → 從 (900,300) 拖曳到 (600,300)（往左約 300 像素），捲動後顯示「迷宮⾜英靈戰役⾜英靈遠征⾜祕境」，祕境圖示在最右側 → 點「祕境」圖示 (約830,425) 進入。

| 元素 | 座標 |
|---|---|
| 古代城堡關卡（點選） | (417,443) |
| 今日可進入次數（讀取用） | 約 (1057,456) |
| 掃蕩按鈕 | (816,508) |
| 自動挑戰勾選框 | (838,568) |
| 關閉（回祕境征戰入口頁） | (1085,81)，關閉後仍在入口頁（副本頁籤），需再點入口頁右上角關閉鈕（約973,153）才真正回主城；**若下一項是地下迷宮，可直接點入口頁裡的「迷宮」圖示接續，不用先回主城** |
| 消耗次數確認視窗「確定」 | (724,424)，**此為每日免費額度消耗，允許點擊** |
| 消耗次數確認視窗「取消」 | (489,424) |
| 掃蕩結果「獲得物品」清單彈窗「確認」 | (602,547) |
| 次數用完提示視窗「取消」 | (487,481) |
| 次數用完提示視窗「確認（消耗秘境鑰匙）」 | (723,481)，**禁止點** |

流程：
1. 確認人物在天空之城，依進入方式開啟祕境畫面。
2. 截圖確認選中的是古代城堡；不是就點選 (417,443)，再截圖確認外框變橘、推薦戰力約 3,400,000。
3. 截圖讀「今日可進入次數」。為 0 則不執行，回報「次數為0，未執行」。
4. 大於 0：確認「自動挑戰」已勾選 (838,568)，未勾就點上。
5. 點「掃蕩」(816,508)，必定會跳出消耗次數確認視窗，點「確定」(724,424) 才真正執行掃蕩。
6. 等待約 2–3 秒，跳出「獲得物品」清單彈窗，截圖記錄掉落內容，點「確認」(602,547) 收下（機制自動發放，不算主動領獎）。
7. 確認「今日可進入次數」減 1，畫面回到關卡列表。
8. **若步驟5後跳出的是「次數已用完，是否使用秘境鑰匙」視窗**：立刻點「取消」(487,481)，停止本模式，回報「次數已用完，已跳過，未使用秘境鑰匙」。
9. 重複步驟 5～8，直到次數變 0 或連續兩次出現用完提示（每天最多 2 次）。
10. 完成後點關閉 (1085,81) 回征戰入口頁。若下一項是地下迷宮，可直接點入口頁裡的「迷宮」圖示接續；否則再點入口頁右上角關閉鈕 (約973,153) 回主城；每一步都截圖確認。

## 回傳給主流程的資料

開始次數 → 結束次數；每次掃蕩的掉落物清單；異常（次數已用完提示、誤點等，無則寫「無」）。
