# 星曲：地下迷宮

執行本檔前，`xingqu-core-rules` 必須已在上下文中。

規則：地下城市有「地下迷宮」「深淵迷宮」「煉獄迷宮」三種子關卡，**本模式只打「地下迷宮」**。每日固定 1 次免費挑戰機會（每日重置），可勾選「使用迷宮鑰匙獲得雙倍收益」消耗鑰匙換雙倍獎勵——**本 skill 固定每次都勾選**（使用者自行每天備齊鑰匙庫存，這是「不主動花費資源」原則唯一明確例外）。

畫面資訊：視窗標題固定顯示「地下迷宮」，左側 3 個子分頁（地下迷宮、深淵迷宮、煉獄迷宮，由上到下），點選後外框變橘色。**注意**：開啟視窗時預設選中的分頁不一定是「地下迷宮」，每次都要先確認外框顏色，不對就點切換。右側還有「我的記錄：N」（歷史最高通關層數）。

前置條件：人物要在「天空之城」。

**進入方式**：主城右下角「征戰」(約1113,538) → 預設在「副本」頁籤 → 點「迷宮」圖示（副本頁籤裡「戰役／迷宮／英雄之門／英靈戰役」這排圖示的第二個，約662,297，不需要拖曳）→ 點左側「地下迷宮」分頁（約157,167），確認外框變橘、標題顯示「地下迷宮」。若是紙祕境關閉後接續執行，可以直接點「迷宮」圖示，不用先回主城。

| 元素 | 座標 |
|---|---|
| 左側分頁「地下迷宮」 | (157,167) |
| 左側分頁「深淵迷宮」／「煉獄迷宮」（不使用） | (157,233) ／ (157,299) |
| 「使用迷宮鑰匙獲得雙倍收益」勾選框 | 約 (497～508,508)，**每次都要勾選**，座標實測有小幅飄動，以截圖為準 |
| 掃蕩按鈕 | 約 (643～655,561) |
| 「今日挑戰次數：X/1」（讀取用） | 約 (643,611) |
| 「迷宮掃蕩」層數選擇畫面「開始掃蕩」 | 約 (718～729,532)，層數預設值等於「我的記錄」，不需調整 |
| 同畫面「取消」 | 約 (474～485,532) |
| 「獲得物品」清單「確定」 | 約 (598～610,532) |
| 視窗右上角關閉鈕（回征戰副本入口頁） | 約 (1061～1068,91) |
| 征戰入口頁右上角關閉鈕（回主城） | 約 (963,154) |

流程：
1. 確認人物在天空之城，依進入方式開啟視窗並確認已切到「地下迷宮」分頁。也可改看主城左側「今日目標」清單裡「地下迷宮 剩餘次數 (X/1)」快速確認（次數用完後這一行會從「今日目標」清單消失）。
2. 截圖讀「今日挑戰次數：X/1」。若為 0：不執行，回報「次數為0，未執行」（點掃蕩會直接顯示「今日次數用完!」横幅，屬正常，不用重試）。
3. 大於 0：先確認「雙倍收益」勾選框已勾選（預設未勾選，未勾就點上，再截圖確認框內出現打勾符號）。**若出現任何「鑰匙不足」「是否消耗鑽石購買鑰匙」之類視窗，一律不點確認／購買，立刻取消並停止回報。**
4. 點擊「掃蕩」，跳出「迷宮掃蕩」層數選擇畫面，層數輸入框預設值不需調整，點「開始掃蕩」。
5. 約 2 秒後直接結算，跳出「獲得物品」清單（上方顯示經驗數字，下方是各種審石⾜材料圖示與數量）。注意：**彈窗不會顯示消耗了幾把鑰匙，也沒有「雙倍」字樣，雙倍收益的實際數值無法從畫面驗證**，回報時只需註明「已勾選、未出現鑰匙不足視窗」即可，不用判斷是否生效。截圖記錄內容後點「確定」關閉。
6. 確認「今日挑戰次數」變 0/1。
7. 完成後（或次數為0跳過後）點視窗右上角關閉鈕回征戰副本入口頁，再點入口頁右上角關閉鈕 (963,154) 回主城（若下一項是紫晶礦場，可直接點入口頁「玩法」頁籤接續，不用先回主城）；每一步都截圖確認。

## 回傳給主流程的資料

開始次數 → 結束次數；掃蕩獲得的經驗⾜道具清單；是否成功勾選雙倍收益、是否出現鑰匙不足視窗；異常（無則寫「無」）。
