# 星曲：徵收

執行本檔前，`xingqu-core-rules` 必須已在上下文中。

規則：內城「內政廳」每日有 5 次免費徵收，每次徵收直接獲得黓金。5 次免費額度用完後，同一位置的按鈕會變成「額外徵收」並標示 💎10（要花鑽石），**本 skill 只用免費的5次，額外徵收絕對不點**。

前置條件：人物要在「內城」。

**進入方式**：內城畫面左側工具列的時鐘圖示 (213,206) → 左側展開佇列清單，找到文字「可徵收 X/5」的一行（約 80,312，清單順序可能變動，**以文字為準**）→ 點擊後跳出「內政廳」視窗。

| 元素 | 座標／說明 |
|---|---|
| 左上角地圖切換區塊「內城」 | 見 xingqu-core-rules 第11條，以文字標籤為準 |
| 左側時鐘圖示 | (213,206) |
| 佇列清單「可徵收 X/5」 | 約 (80,312)，以文字為準 |
| 內政廳「本日可免費徵收次數」（讀取用） | 約 (370,470) |
| 內政廳「可徵收黓金」（讀取用） | 約 (365,508) |
| 「徵收」按鈕 | 約 (865～876,508)，免費次數用完後變成「額外徵收 💎10」，**禁止點** |
| 「升級」按鈕 | 約 (865～876,397)，**不在範圍內，不要點** |
| 內政廳關閉鈕 | 約 (955～965,143) |

流程：
1. 依前置條件切到內城，截圖確認右上角顯示「內城」。
2. 記下開始時的黓金與鑽石數字（畫面右上角）。
3. 點時鐘圖示 (213,206)，截圖讀出「可徵收 X/5」。若為 0/5：不執行，回報「次數為0，未執行」，跳到步驟7。
4. 點「可徵收 X/5」，跳出內政廳視窗，截圖讀出「本日可免費徵收次數」與「可徵收黓金」。
5. 點「徵收」，**一次只點一下**，每次點完截圖確認：免費次數減 1、黓金增加、按鈕文字仍是「徵收」。
6. 重複步驟 5，直到免費次數變 0。此時按鈕會變成「額外徵收」並標示 💎10，**立刻停止，不要點**。
7. 點關閉鈕關閉內政廳，截圖記下結束時的黓金與鑽石數字（鑽石應不變；若鑽石減少，立刻停止並在回報中列為異常）。

不在範圍內：內政廳「升級」、額外徵收、時鐘清單裡「可徵收」以外的其他佇列項目。

## 回傳給主流程的資料

免費次數 X/5→0/5；黓金開始→結束（增加量）；鑽石開始→結束（應不變）；異常（無則寫「無」）。
