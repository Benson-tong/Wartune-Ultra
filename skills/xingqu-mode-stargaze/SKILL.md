# 星曲：觀星

執行本檔前，`xingqu-core-rules` 必須已在上下文中。

規則：點「觀星」後系統自動尋路、自動完成，每日可獲得 3 次觀星機會（每日重置），每次扣除 1 次機會同時獲得 1 次獎勵。次數為 0 時點「觀星」按鈕沒有反應，安全空點不會出錯。

前置條件：人物要在「外城」。若上一個模式是徵收（內城出發），切換地圖時點右上角地圖區塊**下格**的「外城」；若是從天空之城出發，則是**上格**。一律依文字標籤位置、不硬記哪格（見 xingqu-core-rules 第11條）。

**進入方式**：外城畫面右側有一排直向排列的圖示（外城、內城、天空之城、家園按鈕下方），五苒星圖樣的圖示就是觀星入口（有次數可用時圖示右上角會有紅色提示點），固定位置在 UI 面板上、不受地圖拖曳捲動影響 → 點擊後跳出羅盤／星盤介面（下方顯示「今日次數:X/3」與「觀星」按鈕）。

| 元素 | 座標 |
|---|---|
| 觀星入口圖示（外城畫面右側直排） | 約 (1070～1081,238) |
| 「今日次數:X/3」文字（讀取用） | 約 (905,388) |
| 「觀星」按鈕 | 約 (915～928,425) |
| 關閉羅盤介面（右上角） | 約 (991～1003,372) |

流程：
1. 確認人物目前在外城；不是就先切換地圖。
2. 依進入方式點擊觀星入口圖示，跳出羅盤介面，截圖確認「今日次數」剩餘量。
3. 若次數為 0：不執行，回報「次數為0，未執行」，點關閉後跳到下一步。
4. 大於 0：點擊「觀星」按鈕。畫面下方會顯示「觀星自動尋路中……」，人物自動移動（有進度條），全程通常約 8～15 秒，有時最長可能達 45 秒左右，**不需任何額外點擊、不會跳出確認視窗、不需選擇地點或對象**。
5. 尋路完成後系統會自動彈出「觀星獲得：星之火 xN，星之願 xM」，獎勵自動發放（機制自動發放，不算主動領獎）。過程中若看到「已成功捕擈一次，獲得：海洋金幣…」之類系統横幅，這是被動機制（捕擗），當作背景訊息忽略，不算異常。
6. 截圖確認「今日次數」減 1，記錄本次獲得的星之火／星之願數量。
7. 重複步驟 4～6，直到「今日次數」變 0/3。
8. 完成後點關閉，觀星通常是執行順序中最後一個遊戲模式，完成後停留在外城即可，接著回報。

## 回傳給主流程的資料

開始次數 → 結束次數；每次獲得的星之火⾜星之願數量明細；異常（無則寫「無」）。
