# Wartune-Ultra

星曲（Wartune Ultra，7road 網頁版，伺服器 Cloud City）自動遊玩。

這個 repo 收錄一組 **Claude Skills**：讓 Claude 透過「Claude in Chrome」擴充功能，在你的 Chrome 分頁裡代打星曲的每日項目，打完後彙整成一份回報。所有操作都只用免費次數，不花鑽石、不買次數、不對真人玩家出手。

## 技能一覽

所有技能都在 [`skills/`](skills/) 資料夾，每個子資料夾是一個技能（內含一份 `SKILL.md`）。

### 核心

| 技能 | 用途 | 誰會呼叫 |
|---|---|---|
| [`xingqu-auto-play`](skills/xingqu-auto-play/SKILL.md) | **主流程**。判斷要跑哪些項目、依序呼叫子技能、最後彙整回報 | 你說「星曲」時 |
| [`xingqu-core-rules`](skills/xingqu-core-rules/SKILL.md) | 共用規則庫：安全準則、禁點清單、對手選擇、地圖確認、連線健康檢查 | 由主流程／子技能自動載入，不需直接叫 |

## 事前準備

1. **Claude 帳號**，可使用 Skills 功能（claude.ai 桌面版／網頁版，或 Claude Code 皆可）。
2. **Claude in Chrome 擴充功能**：已安裝並連線。技能是用 `mcp__claude-in-chrome__*` 工具操作瀏覽器，沒有它就無法運作。
3. **在 Chrome 開好遊戲**：登入 `7.wan.com/game/play`，選 **Cloud City** 伺服器並進到主城畫面。
   - Claude 遇到登入頁／斷線**不會**自己按「進入遊戲」（預設伺服器可能不是 Cloud City），會停下來請你處理。
4. **視窗大小**：技能內的座標以 **1214×667** 的截圖為準。瀏覽器視窗大小差太多時座標會偏，Claude 雖然每次都會先截圖再點，但仍建議固定同一個視窗大小。
5. **資源**：地下迷宮固定勾選「雙倍收益」，請自備每日的**迷宮鑰匙**。鑰匙不足時 Claude 會取消，不會花鑽石買。

> ⚠️ **安裝前先填入自己的資料**：技能檔裡的帳號、角色名與玩家名稱都已換成佔位符號，請依下表取代成實際內容（全部取代即可），並依自己的戰力調整「外城打怪只打 160 級」等等級條件（見 `xingqu-mode-outer`）。
>
> | 佔位符號 | 填入什麼 | 出現在 |
> |---|---|---|
> | `<你的帳號>` | 你的遊戲帳號名稱 | `xingqu-auto-play`、`xingqu-core-rules` |
> | `<你的角色名>` | 你在遊戲裡顯示的角色名稱（秘銀礦場靠它在房間裡找到自己站的格位） | `xingqu-mode-mithril-mine` |
> | `<白名單對手A>`、`<白名單對手B>` | 英靈競技中「戰力略高於你也願意挑戰」的對手，A 優先於 B；不需要的話可刪掉這段規則 | `xingqu-mode-arena` |
> | `<形似名字>` | 名字跟白名單對手很像、但不能算進白名單的玩家（提醒 Claude 別認錯） | `xingqu-mode-arena` |
> | `<某玩家>` | 只是實測紀錄裡的範例玩家名，不需要改 | `xingqu-mode-mithril-mine` |

## 安裝技能

13 個技能**全部都要安裝**，因為主流程會依名稱呼叫子技能，`xingqu-core-rules` 缺了整個流程會直接停止。

### 方式 A：claude.ai／Claude 桌面版（上傳 zip）

1. 下載本 repo（`Code` → `Download ZIP`，或 `git clone`）。
2. 把 `skills/` 底下**每個資料夾各自壓成一個 zip**（zip 內第一層要是該資料夾，例如 `xingqu-auto-play/SKILL.md`）。Windows PowerShell 一次打包：

   ```powershell
   New-Item -ItemType Directory -Force dist | Out-Null; Get-ChildItem skills -Directory | ForEach-Object { Compress-Archive -Path $_.FullName -DestinationPath "dist\$($_.Name).zip" -Force }
   ```

3. 到 **Settings → Capabilities → Skills**，逐一上傳 `dist/` 裡的 13 個 zip，並確認都已啟用。

### 方式 B：Claude Code（複製資料夾）

把 `skills/` 底下的資料夾複製到個人技能目錄即可：

```bash
cp -r skills/xingqu-* ~/.claude/skills/
```

### 確認安裝成功

在 Claude 的技能清單裡應該看得到 `xingqu-auto-play`、`xingqu-core-rules` 與 11 個 `xingqu-mode-*`（名稱前面可能帶 `anthropic-skills:` 之類的前綴，屬正常，技能會自動用清單上的完整名稱呼叫）。

## 怎麼用（對 Claude 說什麼）

先確認 Chrome 的遊戲分頁已開在主城畫面，然後在 Claude 對話框輸入：

| 你想做的事 | 範例指令 |
|---|---|
| 跑完每日 8 項 | `星曲`、`跑星曲`、`星曲日常` |
| 只跑某一項 | `星曲 只跑紫晶礦場`、`幫我打一下英靈競技` |
| 跑其中幾項 | `星曲：徵收和觀星就好` |
| 英靈島自動戰鬥 | `英靈島` |
| 保衛英靈島 | `保衛英靈島` |
| 秘銀礦場巡邏一次 | `秘銀礦場` |

說明：

- 說「星曲」就等於**授權整套流程**，Claude 不會每一步都問你；只有遇到技能裡沒寫的狀況才會停下來問。
- 指名項目時**只跑你指名的**，依預設順序排列，不會順便補跑其他項目。口語說法如「礦場」「星星」「內政廳」也認得；認不出來時 Claude 會列出支援的項目請你確認。
- 某一項剩餘次數已是 0 時，會回報「次數為 0，未執行」並跳到下一項。
- 某一項失敗（技能呼叫失敗、畫面跟文件對不上）只會停掉該項，其他項目照跑。
- 開工前 Claude 會先做**連線健康檢查**（對分頁截圖一次）；失敗重試 2 次仍不行，就整個停止並請你重新連接 Claude in Chrome。

### 執行時間參考

| 項目 | 約略耗時 |
|---|---|
| 每日 8 項全跑 | 約 1 小時 20 分（例：06:09 開始、07:27 結束） |
| 外城打怪（普通 5＋精英 3） | 約 22 分鐘 |
| 保衛英靈島 | 約 17 分鐘（走到第 4 層約 3 分鐘＋打怪約 14 分鐘） |
| 英靈島 | 30 分鐘（自動，Claude 按下開始後即可結束對話） |

## 每日建議排程

技能本身不內建排程，時間由你自己排（或用 Claude 的排程功能）。以下是目前實際在用的時間線（台北時間，遊戲每日 05:00 重置）：

| 時間 | 任務 | 說明 |
|---|---|---|
| 05:30 | 英靈島 | 約 06:01 自動結束，角色會留在島內 |
| 06:04～06:09 | 星曲（8 項） | 開始前先從英靈島「返回」天空之城 |
| 星曲結束後 | 保衛英靈島 | 07:00～08:10 間結束就直接打 07:00 場；晚於 08:10 就改排 10:00 場；當天已打過就不打 |
| 每小時 :20（UTC） | 秘銀礦場巡邏 | 持續到你說「暫停」為止 |

**優先順序**：秘銀礦場巡邏 ＞ 星曲各項 ＞ 保衛英靈島／英靈島。撞期時 Claude 會先打完當前這一隻、退出副本去巡邏，有空檔再回來。

> 排程注意（寫在 `xingqu-core-rules` 第 14 條）：排程要用**綁定目前對話**的方式（`send_later`），不要用會開全新工作階段的觸發器，否則新的工作階段沒有 Claude in Chrome，排到了也無法操作瀏覽器。排程訊息要寫成完整、獨立的指令（新的執行沒有前面的記憶）。

## 安全規則：Claude 絕對不會做的事

完整清單見 [`xingqu-core-rules`](skills/xingqu-core-rules/SKILL.md)，重點：

- ❌ 花鑽石、道具、金幣：「購買挑戰次數」、英靈競技右下「＋」、祕境「使用秘境鑰匙」、內政廳「額外徵收 💎10」、守衛遠征「＋」、保衛英靈島「使用傳送符」……誤開會立刻取消並回報。
- ❌ 對真人玩家出手：秘銀礦場**不挑戰、不掠奪**，被搶走也不反搶。
- ❌ 打 BOSS（外城打怪）。
- ❌ 主動領獎、開信箱領信（機制自動發放的獎勵除外，例如掃蕩結果、累勝獎勵彈窗）。
- ❌ 斷線時自己重新登入、自己重新整理網頁。
- ❌ 接受副本／組隊／篝火等邀請（一律關閉或拒絕）。
- ❌ 做技能文件以外的事：多人競技場、商店、深淵／煉獄迷宮、高級礦車、內政廳升級……都不碰，要做請另外交代。

**允許的例外**（都是免費額度內的必經確認）：祕境「消耗 1 次今日進入次數」、紫晶礦場領取普通礦車、守衛遠征一鍵掃蕩確認、地下迷宮雙倍收益勾選（用你自備的鑰匙）。

操作習慣：**先截圖再點、一次一個動作**，每點完都再截圖確認結果；地圖切換一律看文字標籤，不憑記憶座標。

## 回報內容

跑完後 Claude 會用表格整理一份回報，包含：

1. 本次執行範圍（全部 8 項，或你指定的項目）。
2. 每一項的開始 → 結束數值（積分、次數、資源），以及逐場／逐次明細。
3. 被跳過的項目（次數為 0）與呼叫失敗的項目。
4. 異常彙整：誤點、彈窗、座標偏差、資源異常等。
5. 尚未回答的問題（如果有）。

輸了就寫輸，不美化。

## 常見問題

**Q：Claude 說「共用規則載入失敗，未執行任何項目」？**
`xingqu-core-rules` 沒安裝或沒啟用。確認 13 個技能都已安裝。

**Q：Claude 說「連線異常，未執行任何項目」？**
Claude in Chrome 斷線。重新連接擴充功能、確認遊戲分頁還開著，再說一次「星曲」。

**Q：點的位置一直偏掉？**
多半是視窗大小改變。把瀏覽器調回接近 1214×667 的遊戲畫面；若遊戲改版導致座標變動，修改對應技能的座標表（見下方「維護與擴充」）。

**Q：我正在手動玩，排程會不會干擾？**
星曲、英靈島、保衛英靈島在你手動遊玩時**照樣執行**，因為共用同一個分頁，點擊可能互相干擾；回報裡會註明有沒有碰撞。想避開的話，手動玩之前先暫停排程。

**Q：保衛英靈島顯示紅字「今日獎勵次數已達上限」，但我今天還沒打？**
這是遊戲已知 BUG（前一天的數字殘留）。Claude 會先打一隻怪判斷：數字變回綠色就是殘留、繼續打；仍是紅色全滿才當作今日已完成。

**Q：英靈島的「今日剩餘收益次數 0/60」是什麼意思？**
雖然標籤寫「剩餘」，數字其實是**已完成**的進度：0/60 是還沒開始，60/60 才是今天完成。

## 維護與擴充

- **改座標／流程**：直接編輯對應技能的 `SKILL.md`，改完重新打包上傳（或重新複製到 `~/.claude/skills/`）。技能檔裡的日期註記（例如「2026-10-04 實測」）代表該資訊最後驗證的時間。
- **新增項目**：
  1. 先建立一個新的 `xingqu-mode-<名稱>` 子技能，寫清楚入口、操作步驟、資源消耗規則、回報格式。
  2. 先用「指名」的方式單獨測試，穩定之後才加進 [`xingqu-auto-play`](skills/xingqu-auto-play/SKILL.md) 的「預設完整順序與子技能對應表」。
  3. 沒列在對應表、你當次也沒指名的項目，Claude 一律不會執行。
- **同步**：本 repo 的技能內容同步自 2026-10-23 Claude 中已安裝的版本。之後在 Claude 裡修改技能，記得再同步回這裡。
