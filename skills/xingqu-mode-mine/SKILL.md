# 星曲：紫晶礦場

執行本檔前，`xingqu-core-rules` 必須已在上下文中。

規則：全程免費的每日采集活動。每日可領取「普通礦車」2 次（每日重置）。每次領取礦車後可進行 5 次免費采集，每次固定獲得 20 礎石，5 次共 100 礎石（畫面礎石上限顯示 200，但免費采集只夠采到 100）。采集完成後，點擊原本「領取礦車」按鈕位置（此時文字變成「提交礦車」）即可交付，礎石依 1:1 轉換成「紫晶」（100 礎石 → 100 紫晶）。另有「高級礦車」僅每日 20:30-21:00 可領取，**本 skill 不處理高級礦車**。

畫面資訊：進入後**人物會被傳送到紫晶礦場專屬場景**（岩石礦區，不是天空之城），畫面右上角出現常駐 HUD 面板，顯示「普通收益」「剩餘采集次數：X」「紫晶：N」「礎石：X/200」「查看獎勵」按鈕、以及「領取礦車(X/2)」（已領取時變「提交礦車(X/2)」）。**這個 HUD 沒有關閉鈕**，離開方式是點場景右下角的「返回」（見步驟 11）。在礦場場景裡，征戰與地圖切換都無法使用。

前置條件：從「天空之城」進入。

**進入方式**：主城右下角「征戰」(約1113～1124,538) → 左側「玩法」頁籤 (約159～170,365) →「紫晶礦場」圖示 (約678～687,297)，進入後人物被傳送到礦場場景、右上角出現 HUD。

| 元素 | 座標／說明 |
|---|---|
| 「領取礦車」／「提交礦車」按鈕（同一位置，文字依狀態變化） | 約 (1040～1058,232) |
| 「領取提示」確認視窗「取消」 | 約 (505～516,397) |
| 「領取提示」確認視窗「確認」 | 約 (675～687,397)，**免費領取，非資源消耗，允許點擊**；按鈕常常要點 2～4 次才會跳出彈窗（2026-10-04 實測仍需多次點擊），每次點完等約1秒、截圖確認，不要連續快點 |
| 地圖／全域圖示（開啟小地圖） | 約 (912～922,230) |
| 小地圖右側「點選前往」清單「紫晶原礎」 | 約 (846～858,457)，點了會沿黃色虛線自動尋路到采集區 |
| 小地圖視窗關閉鈕 | 約 (964～975,144) |
| 采集區紫晶水晶簇 | **無固定座標**，抵達采集區後畫面四周會出現大片紫色水晶簇。**只有頭上出現黃色「採集紫晶」標籤的水晶才能觸發采集**（2026-10-04 實測：點沒有標籤的水晶或地面完全無效，曾因此白白浪費約 4 分鐘）；標籤在人物自動尋路停下、站定不動之後才會出現，所以抵達後要先等人物停穩（等 3～5 秒、截圖確認），再點有標籤的那一簇 |
| 礦場場景右下角「返回」（門形圖示） | (1113～1124,541～543)，**離開礦場、回天空之城的唯一方式** |

流程：
1. 依進入方式開啟紫晶礦場 HUD。
2. 截圖讀「領取礦車(X/2)」剩餘次數。若為 0/2：不執行，回報「次數為0，未執行」，跳到步驟11離開礦場。
3. 大於 0：點擊「領取礦車」，跳出「領取提示」確認視窗，點「確認」（可能需點數次，每次都重新截圖確認）。
4. 領取成功後確認「剩餘采集次數」變成 5，HUD 按鈕文字變成「提交礦車」，人物旁邊出現一台裝著紫色水晶的礦車。
5. 尋找采集目標：點小地圖圖示 → 點右側清單「紫晶原礎」 → 小地圖上會出現黃色虛線路徑、人物開始自動尋路 → 點小地圖關閉鈕 → 等約 4 秒抵達采集區，**再等人物完全停穩（不再移動）**，截圖確認四周出現大片紫色水晶簇。**每輛礦車都要重做這一步**（交付第一輛後人物停在交付點，附近看不到水晶簇，需重新用小地圖尋路過去）。
6. 在截圖中找出頭上有黃色「採集紫晶」標籤的大水晶簇並點它，畫面下方出現「采集中」與進度條即為成功；若點了沒反應，不要連續亂點，改找另一簇有標籤的、或等人物停穩後重截圖。**避開事項**：不要點自己的礦車或車上的水晶（會再跳一次領取提示彈窗，點「取消」即可，不會重複領車、不影響額度）；不要點人物周邊的金色圖示（會開啟活動面板，見 xingqu-core-rules 第10條）。
7. 觸發後人物會自動反覆采集（每次約2～3秒、+20礎石），不需再點擊，持續截圖確認「剩餘采集次數」與「礎石」數字變化，直到剩餘次數變 0、礎石 100/200。
8. 采集次數歸零後，點擊 HUD 上的「提交礦車」按鈕——**需點擊兩次**：第一次點完人物頭上顯示「運輸中」、開始走回礦車交付點；**等約 10 秒**（2026-10-04 實測約 10 秒才走到；先前文件寫 6～8 秒偏短），確認人物已抵達（頭上顯示「礎石 100」、不再移動）後再點第二次，才真正完成交付。
9. 交付成功後畫面中央與系統訊息出現「提交成功，獲得100紫晶」（機制自動發放，不算主動領獎），確認「礎石」歸零、「紫晶」增加 100、按鈕變回「領取礦車(X/2)」且 X 減 1。
10. 若當日還有礦車額度（X 不為 0），回到步驟 3 領取下一輛，直到「領取礦車(0/2)」。按鈕變成 0/2 後若不小心點擊，畫面沒反應、不會跳出任何視窗，屬正常安全狀態。
11. **離開礦場**：點場景右下角「返回」，人物會回到天空之城；截圖確認右上角地圖名稱顯示「天空之城」、右下角「征戰」恢復可用，才繼續下一個模式。

## 回傳給主流程的資料

開始紫晶 → 結束紫晶；礦車領取／提交次數（0/2→2/2）；每次領取礦車采集到的礎石總量；異常（無則寫「無」）。
