# 星曲子技能：單人競技＋英靈競技（xingqu-mode-arena）

由主 SKILL `xingqu-auto-play` 依序呼叫（或使用者指名「單人競技」「英靈競技」時單獨呼叫），代打「單人競技」與「英靈競技」，呼叫一次依序完成兩者。執行前提：主流程已呼叫 `xingqu-core-rules` 並套用其中的通用安全規則（截圖後才點擊、彈窗處理、地圖確認、絕對不點清單等）與「對手選擇規則（單人競技／英靈競技共用）」；若被單獨呼叫且尚未載入 `xingqu-core-rules`，先呼叫該 skill 取得上述規則。

## 對手選擇規則（延伸）

基本規則（只打戰力低於我的對手、同條件中選積分最高者、有確認視窗先看勝負分再確認、沒有符合對手時換名單）請見 `xingqu-core-rules`。英靈競技在此基礎上，另有以下延伸規則：

允許在戰力略高於我時仍挑戰的對手：「<白名單對手A>」與「<白名單對手B>」（注意名單中可能出現「<形似名字>」等形似但不同的名字，不算在許可名單內）。這兩位的優先順序：

1. 優先打戰力低於我的一般對手（依基本規則挑積分最高者）。
2. 沒有符合的一般對手時，先考慮「<白名單對手A>」（若在名單中）。
3. 只有<白名單對手A>不在名單中、且沒有其他符合的一般對手時，才考慮「<白名單對手B>」。
4. 兩位都不在名單、也沒有一般對手時，依基本規則的「換名單」流程處理。

### 連敗對手跳過規則（使用者 2026-10-06 指定，英靈競技適用）

- 若對「同一位對手」已連續輸 3 場以上，這位對手本輪跳過，改打名單中符合條件（戰力低於我、或上方許可名單）且積分次高的對手。
- 連敗紀錄以「戰報」逐場紀錄核對（先點戰報看最近幾場對該對手的結果，不憑記憶）。
- 該對手之後只要有贏過一場，連敗歸零，恢復依基本規則（積分最高優先）。
- 跳過後名單內已無其他符合條件的對手時，依基本規則的「換名單」流程處理；換名單用完仍沒有可打對象就停止並在回報註明，不硬打連敗對手。
- 此規則的解讀（「連敗對手」指同一位對手連輸 3 場以上）為依使用者回覆「連敗的對手幫我跳過」所做，回報中若遇到判定有疑義的情況要如實註明。

## 模式一：單人競技

**規則**：挑戰其他玩家，勝得積分、敗扣積分；每週結算後積分衰減；積分達門檻領道具獎勵；每週累計獲勝場次達標（10／20／35／50 次）時彈出累勝獎勵彈窗。每日 10 次挑戰。

**畫面資訊**：左上角「我的積分、我的戰力、剩餘次數」；中間「刷新倒計時、剩餘免費刷新次數」；下方 4 位對手各有積分與戰力。

**進入方式**：主城右下角「征戰」(1118,545) → 左側「競技」(171,297) →「競技場」(370,297)。「競技場」是入口頁，左邊多人競技場、右邊單人競技場；點右邊「開始挑戰」(852,548) 才進入單人競技名單。入口頁右上角關閉鈕 (1132,74) 只在入口頁可回主城。

**座標（1214x667）**：

| 元素 | 座標 |
|---|---|
| 4 位對手的「挑戰」按鈕 | (257,607) (492,607) (728,607) (964,607) |
| 刷新按鈕 | (736,165) |
| 返回（右下角門） | (1120,612)，去向不固定（可能回競技場入口頁或直接回主城），按完必須截圖確認 |
| 入口頁「單人競技場 開始挑戰」 | (852,548) |
| 入口頁關閉（回主城） | (1132,74)，只在入口頁使用 |

**流程**：

1. 截圖，讀出我的戰力、剩餘次數，以及 4 位對手的積分與戰力。
2. 依對手選擇規則挑一位，點該位「挑戰」；單人競技點下去直接進戰鬥，沒有確認視窗。
3. 戰鬥載入約 5～8 秒（首次更久），出現戰鬥畫面後點「跳過」(1061,424)；若仍顯示「自動戰鬥中」而沒有「勝利／失敗」字樣，再點一次。
4. 戰鬥結算後約 6 秒自動回到名單，以「剩餘次數減 1」與積分變化確認結果。
5. 若遇到累勝獎勵彈窗（只有「領取」一個按鈕，點視窗外空白處或 Esc 都關不掉）：直接點「領取」關閉，這是免費道具獎勵不算主動領獎，繼續往下打，並在回報中註明遇到此彈窗。
6. 每場後名單不一定自動刷新；沒有符合對手時按刷新 (736,165)，每天僅 3 次免費刷新，用完後就打現有名單裡符合條件者，再沒有就停止並回報。不花鑽石刷新。
7. 剩餘次數 0/10 時停止；畫面底部會出現「購買挑戰次數」，不要點。

## 模式二：英靈競技

**規則**：單個玩家的英靈 3V3 對戰；每日 10 次機會，每日 5:00 重置；每週一凌晨 5 點結算積分並發獎勵（郵件發放），結算後積分按比例衰減。

**畫面資訊**：右上角「我的排名、當前積分、我的隊伍戰力」；4 位對手各有積分與戰力（戰力數字前有小劍符號）；右下角「剩餘挑戰次數」。

**進入方式**：主城右下角「征戰」(1118,545) → 左側「競技」(171,297) →「英靈競技」(686,298)。每一步都截圖確認再點下一步。

**座標（1214x667）**：

| 元素 | 座標 |
|---|---|
| 4 位對手的「挑戰」按鈕 | (257,500) (510,541) (766,499) (1017,541) |
| 確認視窗「挑戰」 | (775,551) |
| 確認視窗「再想想」 | (437,551) |
| 返回箭頭（左上，回主城，非上一層） | (105,68) |
| 右下角「＋」 | (1143,623)，禁止點 |
| 戰報（查看逐場紀錄） | (100,617) |

**流程**：

1. 截圖，讀出我的隊伍戰力與 4 位對手的積分、戰力。
2. 依對手選擇規則（含上方「<白名單對手A>／<白名單對手B>」優先順序與「連敗對手跳過規則」）挑一位，點該位「挑戰」。
3. 出現確認視窗，可看到「勝利：積分 +N　失敗：積分 −M」，確認是預期對手後按「挑戰」(775,551)。
4. 戰鬥載入約 8～10 秒才出現「跳過」，點「跳過」(1061,424)；若還在戰鬥再點一次。結算後約 3～6 秒回到名單，過程中可能短暫出現主城畫面，屬正常，等待即可。
5. 回到名單時對手欄可能先顯示空白（只有「積分：」與數字的空底座），這是載入中，等 3 秒再截圖，不要在空白名單上點擊。
6. 每場後名單會變動，重新截圖後重複步驟 1～5。
7. 沒有符合對手時（換名單）：點左上角箭頭 (105,68) 回主城 →「征戰」(1118,545) →「競技」(171,297) →「英靈競技」(686,298)，名單會更新，每一步都截圖確認；仍沒有就重複，最多連續 5 次，超過就停止並回報，避免無限迴圈。
8. 若符合的對手只剩積分很低的（例如勝利只+10、失敗−18）且還有次數，可先換名單找更好的，換到最後一次時仍以能打的最高積分對手為準。
9. 剩餘挑戰次數 0 時停止。完成後點「戰報」(100,617) 讀取本次執行期間的逐場紀錄（時間戳從進入英靈競技開始計），核對逐場明細，避免靠記憶拼湊出錯；戰報也會列別人主動挑戰我的紀錄，別混入自己執行的逐場明細。**若戰報明顯沒有反映本輪紀錄**（例如最新時間戳遠早於本次執行時段，這是已知的更新延遲問題）：不用等待或重試戰報，改用截圖記錄的逐場積分變化交叉核對（每場積分變化加總應等於「開始積分」到「結束積分」的差額），並在回報異常欄註明「戰報未能反映本輪紀錄，改用截圖交叉核對」。

## 執行結果輸出（供主流程彙整）

本 skill 執行完成後，需整理以下內容回傳給主流程：

1. 單人競技：開始→結束積分、勝負場數、剩餘次數（X/10）與剩餘免費刷新次數；逐場明細（對手、結果、積分變化）；是否遇到累勝獎勵彈窗。
2. 英靈競技：開始→結束積分、排名、勝負場數、剩餘次數（X/10）；逐場明細（對手、結果、積分變化，優先以戰報核對，戰報異常則寫明改用截圖交叉核對）；是否有套用連敗對手跳過規則（跳過了誰、改打了誰）。
3. 異常與失誤：誤點、需要重點跳過、換名單次數、彈窗處理（含累勝獎勵）、戰報核對失敗等，沒有就寫「無」。
4. 若任一模式因剩餘次數為 0 而未執行，明確寫「次數為 0，未執行」。
